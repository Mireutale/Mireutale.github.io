# 프론트엔드 변경 기록

## 2026-10-22

### 프로젝트 목록 배치와 상세 가독성 개선

- 섹션 이동 메뉴를 제거하고 프로젝트 5개를 이미지 왼쪽·설명 오른쪽의 목록으로 배치했습니다. 모바일에서는 세로로 표시합니다.
- 기존 프로젝트 내용을 유지하면서 상세 설명에 문장별 줄바꿈과 제목·문단 간격을 추가했습니다.
- Fruition의 부하 테스트 설명을 풀어쓰고 기술 목록과 설명에서 불필요한 버전 표기를 제거했습니다.
- 검증: Astro 빌드와 변경 공백 검사 통과. 프로젝트 5개 상세 열기·닫기, 화면 너비 320·390·768·1440px에서 가로 넘침 없음, 상세 줄바꿈과 소제목 여백 적용을 확인했습니다.

### 프로젝트 전체 표시와 역할 설명 보완

- 프로젝트 5개를 모두 카드로 표시하고 기타 개발 경험 구분을 제거했습니다.
- 목차에 사이트 색상과 어울리는 메뉴 스타일과 모바일 2열 배치를 적용했습니다.
- 소개·경력·기술 목록과 프로젝트 설명에 기획·설계·백엔드·프론트엔드·AI 모델 학습·배포·운영 경험을 반영했습니다.
- 검증: Astro 빌드와 변경 공백 검사 통과. 빌드 미리보기에서 카드 5개, 전체 상세 열기·닫기, 목차 색상·밑줄 제거와 모바일 가로 넘침 없음을 확인했습니다.

### 핵심 프로젝트 중심 구성

- 핵심 경험을 먼저 읽을 수 있도록 프로젝트를 경력보다 앞에 배치하고 섹션 목차를 추가했습니다.
- 주요 프로젝트 3개와 기타 개발 경험 2개를 구분하고, 상세 화면에서 직접 사용한 기술과 프로젝트 전체 기술을 나눴습니다.
- 소개·경력·프로젝트 설명을 담당 작업과 문제 해결 과정 중심으로 정리하고 기술별 활용 경험을 표시했습니다.
- 검증: Astro 빌드, 변경 공백 검사, 프로젝트 5개의 상세 열기·닫기, 모바일 페이지 가로 넘침, 목차 연결, 인쇄용 프로젝트 5개 유지를 확인했습니다.
