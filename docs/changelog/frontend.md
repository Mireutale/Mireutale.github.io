# 프론트엔드 변경 기록

## 2026-10-22

- 핵심 경험을 먼저 읽을 수 있도록 프로젝트를 경력보다 앞에 배치하고 섹션 목차를 추가했습니다.
- 주요 프로젝트 3개와 기타 개발 경험 2개를 구분하고, 상세 화면에서 직접 사용한 기술과 프로젝트 전체 기술을 나눴습니다.
- 소개·경력·프로젝트 설명을 담당 작업과 문제 해결 과정 중심으로 정리하고 기술별 활용 경험을 표시했습니다.
- 검증: Astro 빌드, 변경 공백 검사, 프로젝트 5개의 상세 열기·닫기, 모바일 페이지 가로 넘침, 목차 연결, 인쇄용 프로젝트 5개 유지를 확인했습니다.
