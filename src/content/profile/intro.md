# 검색 결과·링크 미리보기에 쓰이는 한 줄 소개
description: "왜 만드는지, 어떻게 동작하는지를 먼저 묻는 개발자"
---

**문제를 깊이 탐구하고 해결 방법을 고민하는 호기심 많은 개발자입니다.**

Pilltip에서는 연구실 서버에 온프레미스 인프라를 직접 구축해 운영하고 YOLOv8 알약 인식 모델을 학습했습니다. Fruition에서는 원문 근거를 연결하고 AI 작업을 위험도에 따라 승인하거나 되돌릴 수 있는 LLM Wiki를 기획·설계했습니다.

Fruition에서는 Terraform으로 AWS EKS 인프라를 구성했습니다. 인증 DB와 Redis를 이중화하고 사용하지 않을 때는 노드를 0대로 줄이도록 절전 기능을 만들었습니다. 모놀리스와 MSA에 같은 k6 시나리오로 AI 요청을 집중시켜 비교한 뒤 인증 응답을 유지할 수 있는 MSA로 전환했습니다.

이 팀에서 함께 쓸 AI 개발 규칙을 정리하고 GitHub Actions OIDC 배포 파이프라인도 만들었습니다.

개인 프로젝트인 분산 동시성 스트레스 테스트에서는 수강신청 상황을 재현해 초당 2,000건의 요청을 보냈습니다. 동시 처리 수를 부하에 따라 조절하도록 바꿔 실패율을 20.79%에서 0%로 낮췄습니다.

- 컨퍼런스와 오픈소스 활동에서 꾸준히 배우고 배운 내용은 팀과 적극적으로 나눕니다.
- 팀 프로젝트에서는 항상 상대를 존중하는 태도로 일합니다.
