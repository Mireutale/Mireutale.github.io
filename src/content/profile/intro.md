# 검색 결과·링크 미리보기에 쓰이는 한 줄 소개
description: "왜 만드는지, 어떻게 동작하는지를 먼저 묻는 개발자"
---

**고민하고 문제를 탐구하는 것을 좋아하는, 호기심 많은 개발자입니다.**

Pilltip에서는 연구실 서버로 온프레미스 인프라를 직접 구축·운영하고 YOLOv8로 알약 인식 모델을 학습했으며, Fruition에서는 원문 근거를 연결하고 AI 작업을 위험도별로 승인·롤백하는 LLM Wiki를 기획·설계했습니다.

AWS EKS 인프라를 Terraform으로 구성해 인증 DB와 Redis는 이중화하고, 사용하지 않을 때 노드를 0대로 줄이는 절전 기능으로 비용을 아꼈습니다. k6로 AI 요청 폭주 상황을 비교해 MSA 전환을 결정했고, 수강신청 부하(초당 2,000건)에서 실패율을 20.79%에서 0%로 낮췄습니다.

팀 공통 AI 개발 규칙과 GitHub Actions OIDC 배포 파이프라인을 만들어 세 명이 같은 기준으로 개발하고 배포하게 했습니다.

- 컨퍼런스와 오픈소스로 꾸준히 배우고, 배운 것은 팀과 적극적으로 공유합니다.
- 팀 프로젝트에서는 항상 상대를 존중하는 태도로 일합니다.
