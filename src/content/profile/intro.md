**고민하고, 문제를 탐구하는 것을 좋아하는 사람입니다.**

- 기획과 아키텍처 설계부터 개발, 배포·운영까지 서비스 전 과정을 직접 맡아 왔습니다.
- 졸업과제 프로젝트 Pilltip에서는 Spring 서버의 전체 아키텍처를 설계하고 JWT 인증과 DB 테이블, 의약품 공공데이터 처리 파이프라인을 구성했으며, 서버를 온프레미스 환경에서 직접 운영했습니다.
- AISW마에스트로 프로젝트 Fruition에서는 팀장으로 기획·설계를 이끌고, 편집기·지식 그래프 화면 개발과 AWS 인프라·배포 자동화를 맡았습니다.
- 설계가 예상대로 동작하는지 직접 측정해 확인한 뒤 결정합니다.
    - 스트레스 부하 테스트에서는 적응형 동시성 제어로 초당 2,000건 부하의 실패율을 **20.79%에서 0%로** 낮췄습니다.
    - Fruition에서는 로컬 환경에서 모의 LLM을 두고 k6로 모놀리스와 MSA에 같은 부하를 보내 비교했습니다. AI 요청이 몰리자 모놀리스는 인증 응답 중앙값이 **9,981ms**까지 늘었고, 10분짜리 AI 작업 30건 중 22건을 접수했지만 모두 실패했습니다. 이를 해결하기 위해 인증·문서 서비스를 분리하고 AI 작업을 Kafka 기반 비동기 워커로 옮긴 구조에서는 인증 응답 중앙값 **7.15ms**를 유지하며 30건을 모두 처리하는 것을 확인하여 구조를 전환했습니다.
- 팀이 AI 도구를 같은 방식으로 쓸 수 있도록 공통 규칙과 공용 스킬을 정리했고, AI가 만든 결과는 코드 리뷰·자동 테스트로 검증한 뒤 반영합니다.

- 컨퍼런스와 오픈소스 활동으로 시야를 넓히며, 항상 더 나은 방법이 무엇인지 고민합니다.
- 팀원의 의견을 존중하고, 배운 내용을 나누며 함께 성장합니다.
- 요즘은 안정적인 인프라를 제공하는 역량을 기르기 위해 클라우드를 공부하고 있으며, AI를 활용해 빠르면서도 신뢰할 수 있는 개발을 하는 방법에 관심이 많습니다.
