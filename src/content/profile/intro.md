# 검색 결과·링크 미리보기에 쓰이는 한 줄 소개
description: "왜 만드는지, 어떻게 동작하는지를 먼저 묻는 개발자"
---

클라우드 인프라와 분산 시스템을 설계하고 운영하는 인프라 엔지니어입니다.

장애가 나도 멈추지 않으면서 비용은 아끼는 클라우드 설계에 관심이 많습니다. AWS EKS 인프라를 Terraform으로 구성하면서, 멈추면 안 되는 인증 DB와 Redis는 이중화하고 나머지는 비용에 맞춰 두었고, 사용하지 않을 때는 노드를 0대로 줄였다가 접속하면 다시 기동하는 절전 기능을 만들었습니다.

요청이 한꺼번에 몰려도 버티는 시스템을 직접 만들고 검증해 왔습니다. 수강신청 상황을 재현해 초당 2,000건 부하에서 실패율을 20.79%에서 0%까지 낮췄고, AI 요청 폭주 상황을 k6로 비교해 MSA 전환을 결정했습니다.

복잡한 흐름을 단순하게 정리해서 팀이 더 빨리 개발하게 만드는 일(Developer Velocity)을 좋아합니다. GitHub Actions OIDC 기반 자동 배포 파이프라인과 팀 공통 AI 개발 규칙을 만들어서, 세 명이 같은 기준으로 개발하고 배포하게 했습니다.

- 컨퍼런스 및 외부 네트워킹을 통해 기술적 시야를 넓히고, 여러 오픈소스를 살펴보며 새로운 기술을 꾸준히 학습합니다.
- 새로 배운 지식은 기술적인 내용이 아니더라도 팀과 적극적으로 공유하며 함께 성장하고자 합니다.
- 팀 프로젝트에서 항상 상대를 존중하는 태도로 프로젝트를 진행합니다.
