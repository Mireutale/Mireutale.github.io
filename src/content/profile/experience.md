기관: 오픈소스 기여
역할: rhwp · Rust 기반 HWP 뷰어·에디터
기간: 2026.06

Rust 기반 HWP 에디터 [rhwp](https://github.com/edwardkim/rhwp)에서 HWPX 파일을 저장할 때 정보가 사라지는 문제를 수정했습니다. 제출한 PR 4건이 반영됐습니다.

- [#1222](https://github.com/edwardkim/rhwp/pull/1222) 본문과 표 안의 문단에 같은 id가 붙어 충돌하던 문제를 고쳤습니다. 문서 전체에서 하나의 카운터를 쓰도록 바꾸고 단위·통합 테스트를 추가했습니다.
- [#1311](https://github.com/edwardkim/rhwp/pull/1311) 표 테두리 대각선이 항상 "없음"으로 저장되던 문제를 수정했습니다. 내부 비트값(BorderFill.attr)을 다시 읽어 올바른 방향으로 저장하도록 했습니다.
- [#1349](https://github.com/edwardkim/rhwp/pull/1349) 그림의 그림자·효과 정보를 읽고 쓸 수 있도록 모델을 추가하고 그룹 안의 그림이 저장되지 않던 문제도 함께 고쳤습니다.
- [#1360](https://github.com/edwardkim/rhwp/pull/1360) 본문 문단의 저장 로직을 재사용해 표 칸 안의 탭과 줄바꿈이 글자 그대로 저장되던 문제를 해결했습니다.
- AI로 코드 흐름을 빠르게 파악한 뒤 기존 파서 코드와 비교했습니다. cargo test·clippy·회귀 테스트로 직접 확인하고 제출했습니다.
