**장애 영향과 비용을 함께 따져 인프라를 구성하고 운영하는 인프라·DevOps 개발자입니다.**

- 배포·운영까지 서비스 인프라를 직접 맡으며 개발자로서 역량을 기르고 있습니다.
    - 장애 영향과 비용을 함께 따져 구성을 결정합니다.
        - Fruition에서는 Terraform으로 AWS EKS 인프라를 구성하고 GitHub Actions OIDC 배포를 자동화했습니다. 월 **400~650달러** 예산 안에서 인증 DB는 Multi-AZ, Redis는 2노드로 이중화하고, 작업이 없을 때 노드를 0대로 줄이는 절전·자동 기동과 모니터링·비용 알림을 구현했습니다.
        - Pilltip에서는 연구실 서버에 Nginx·HTTPS·Docker 배포를 구성해 **6개월** 동안 직접 운영했습니다.
    - AI로 코드를 빠르게 생성하되, 결과는 코드 리뷰·자동 테스트로 검증한 뒤 반영하여 믿을 수 있는 코드를 만듭니다.

- 함께 배우고 성장하는 것을 중요하게 생각합니다.
    - 컨퍼런스와 오픈소스 활동으로 시야를 넓히며, 항상 더 나은 방법이 무엇인지 고민합니다.
    - 팀원의 의견을 존중하고, 배운 내용을 나누며 함께 성장합니다.

- 최근에는 안정적인 인프라를 제공하는 역량을 기르기 위해 클라우드를 공부하고 있으며, AI를 활용해 빠르면서도 신뢰할 수 있는 개발을 하는 방법에 관심이 많습니다.
