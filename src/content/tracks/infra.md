**장애 영향과 비용을 함께 따져 인프라를 구성하고 운영하는 인프라·DevOps 개발자입니다.**

Fruition에서는 Terraform으로 AWS EKS 인프라를 구성하고 GitHub Actions OIDC 배포를 자동화했습니다. 월 400~650달러 예산 안에서 인증 DB는 Multi-AZ, Redis는 2노드로 이중화하고, 작업이 없을 때 노드를 0대로 줄이는 절전·자동 기동과 모니터링·비용 알림을 구현했습니다. Pilltip에서는 연구실 서버에 Nginx·HTTPS·Docker 배포를 구성해 10개월 동안 직접 운영했습니다.

AI 도구를 팀 개발에 활용할 수 있도록 공통 규칙과 공용 스킬을 정리했고, 코드 리뷰·자동 테스트·부하 테스트로 결과를 검증하며 개선해 왔습니다.

- 컨퍼런스와 오픈소스 활동에서 배운 내용을 팀과 나눕니다.
- 팀원의 의견을 존중하고 사용자·멘토 피드백을 설계에 반영합니다.
