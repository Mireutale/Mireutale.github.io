## 왜 만들었나

우아한테크코스 프리코스 오픈미션. "서버가 많으면 되나, 큐로 막으면 되나"가 궁금해서 남의 설명 대신 직접 재현해 보기로 했습니다.

## 어떻게 풀었나

- WebFlux 기반 라운드로빈 로드밸런서 → 서버 인스턴스 3대 → 공유 PostgreSQL 구조. 서버마다 DB를 따로 두면 락 경합이 안 보여서 하나의 DB를 바라보게 했습니다.
- 요청을 우선순위 큐에 넣고 최대 동시 처리 수를 제한. 처음엔 고정값이었는데, 지연 시간을 보고 동시 처리 수를 점진적으로 늘리고 줄이도록 바꾸자 같은 시간에 더 많이 처리하고 실패율은 내려갔습니다.
- k6가 응답을 전부 에러로 잡는 문제를 추적해 보니 로드밸런서가 백엔드 헤더를 그대로 실어 헤더가 두 번 붙고 있었습니다. exchangeToMono로 바디만 넘기도록 수정.
