## 배경

실제 서비스의 API 구조를 배워 보고 싶어 당근마켓을 골랐습니다. 앱에서 상품을 조회하거나 채팅을 보낼 때 오가는 요청을 살펴보고 필요한 API를 직접 설계하는 방식으로 진행했습니다.

## 구조와 구현

- **도메인 설계**: 앱 요청을 분석해 API를 상품·댓글·찜·구매·채팅 5개 도메인으로 나누고 FastAPI와 SQLModel로 모델을 구현했습니다. 비밀번호는 bcrypt로 해싱하고 인증은 JWT(python-jose)로 처리했습니다.
- **실시간 채팅**: 채팅방마다 WebSocket을 연결해 메시지를 실시간으로 주고받게 했습니다.
- **협업·통합**: 개발 전에 4명이 브랜치와 PR 규칙부터 정했습니다. 모듈을 나눠 개발한 뒤 프론트엔드에 하나씩 연결하며 v0.1.0부터 v0.3까지 버전을 올렸습니다.
