## 목표와 담당 작업

실제 서비스의 API 구조와 팀 프로젝트를 수행할 때 협업을 위한 개발 과정을 배우기 위해 당근마켓을 선택하고 클론코딩을 진행해 보았습니다.
주 업무는 아키텍처 설계와 백엔드를 담당했습니다.

- 상품, 댓글, 찜, 구매, 채팅 5개 도메인의 API를 SQLModel 모델을 활용하여 구현하였습니다.
- 비밀번호는 bcrypt로 해싱하고 JWT(python-jose) 인증을 적용했습니다.
- 채팅방마다 WebSocket을 연결해 실시간으로 메시지를 주고받도록 했습니다.
- 개발 전에 4명이 브랜치와 PR 규칙을 정하고 모듈을 React 프론트엔드에 연결하며 통합 할때마다 버전을 다르게 두어 정리했습니다.
