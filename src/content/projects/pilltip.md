## 배경

여러 병원에서 처방받은 약을 함께 먹는 사용자는 복약 이력을 모아 보고 주의사항을 확인하기 어렵다고 생각했습니다. “약 봉투는 왜 아직도 종이일까?”라는 질문에서 시작해 복용 중인 약과 건강 정보를 한곳에서 관리하는 서비스를 만들었습니다.

## 아키텍처

![Pilltip 시스템 아키텍처](/img/pilltip/architecture.png)

Android 앱과 병원용 Next.js 웹은 Nginx(HTTPS)를 거쳐 Spring Boot 서버에 REST 요청을 보냅니다. 서버와 저장소는 Docker 컨테이너로 운영했습니다.

약품 검색과 자동완성은 Elasticsearch, DUR 매핑과 태깅은 Redis, 자연어 질문의 임베딩과 Top-K 검색은 Weaviate가 맡습니다. 사용자·약 정보는 MySQL에 저장하며 암호화와 비식별화를 적용했습니다. 약 안내와 DUR 충돌 설명은 GPT-4o mini가 쉬운 말로 생성하고 복약 알림은 FCM으로 보냅니다.

## 주요 기능

- **개인 맞춤형 DUR**: 사용자의 건강 정보와 복약 이력을 함께 확인해 복용 시 주의사항과 의사 상담이 필요한 경우를 안내합니다. 어려운 의학 용어는 쉬운 말로 풀어 설명합니다.
- **약품 검색 + 위험 태그**: 검색 결과마다 약 성분을 사용자 건강 정보와 비교해 DUR 경고를 태그로 표시합니다. 임산부·병용·노인·연령 주의 여부를 한눈에 확인할 수 있습니다.
- **스마트 복약 알림**: 설정한 시간에 알림을 보내며 사용자가 '먹었어요'를 누르면 바로 기록합니다. 달력에서 복약 완료율도 확인할 수 있습니다.
- **가족 건강 관리**: 만 14세 미만 자녀나 가족 정보를 등록해 두면 터치 한 번으로 계정을 전환할 수 있습니다.
- **스마트 문진표**: 병원 QR 코드를 스캔하면 문진표가 병원 웹으로 전송되고 일정 시간이 지나면 자동으로 삭제됩니다. 병원은 웹에서 환자 문진을 관리합니다.
- **AI 챗봇**: 질문에 따라 DUR을 확인하거나 제품을 추천하고 섭취량을 안내합니다. 제품은 DUR 검사를 통과한 것만 추천하고 답변은 대화체로 제공합니다.

## 담당 구현

- **온프레미스 인프라**: 클라우드 비용이 부담돼 지원받은 연구실 서버를 사용했습니다. 학교 내부망의 서버에 Nginx 리버스 프록시와 포트포워딩을 구성하고 ZeroSSL 인증서로 HTTPS를 적용해 도메인을 연결했습니다. 요청마다 로그를 남겼고 배포부터 장애 대응까지 직접 맡았습니다.
- **알약 인식**: YOLOv8로 알약 인식 모델을 학습했습니다. AI-Hub 경구약제 데이터가 서버 용량보다 커서 데이터를 나눠 받아 이전 가중치에 이어서 학습했습니다. 이전에 학습한 내용을 잊지 않도록 이전 이미지 10%를 함께 넣었습니다. 정답률이 90%를 넘을 때만 다음 묶음으로 넘어갔습니다. 넘지 못하면 에포크와 가중치를 다시 조정했습니다. 여러 알약이 함께 찍힌 고화질 이미지로 검증한 최종 정답률은 92%였습니다.
- **인증·데이터**: JWT 인증과 MySQL 스키마를 설계하고 처방이나 문진 같은 민감한 데이터는 AES-GCM으로 암호화해 저장했습니다.
- **데이터 파이프라인**: 식약처와 심평원에 흩어진 의약품 공공데이터(e약은요, DUR 품목정보, 성분별 1일 최대투여량 등)를 하나로 통합했습니다.
